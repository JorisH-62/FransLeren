# FransLeren 🐌

Een web-app om Frans te leren (uitleg in het Nederlands): grammatica van A1 tot B1,
flashcards met slim herhalen, grappige kinderverhalen, gesprekken met familie oefenen,
een werkwoorden-trainer en Franse uitdrukkingen.

Live: https://jorish-62.github.io/FransLeren/

Geen build-stap nodig: puur HTML/CSS/JavaScript. Lokaal draaien:

```bash
python3 -m http.server 8000
```
